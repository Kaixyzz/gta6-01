**SOLARA BAY — Streets of the Bay** is a top-down 2D open-world crime game in a sun-soaked coastal city. You are a small-time driver working your way up: steal cars, outrun the police, and complete **6 story missions** — from your first stolen wheels to a bank heist and a final showdown for the boss's sports car. Along the way you can hunt **3 hidden stashes**, and steal anything with wheels: regular cars, a fast **motorbike** and a heavy **truck**.

The city is fully explorable on foot and by car, with traffic, pedestrians, a wanted system with real police chases, combat, a HUD with minimap, a title screen, pause menu and save/load. All art is drawn in code and all sound is synthesized with WebAudio — the game runs fully offline from static files.

## How to run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. Controls: **WASD** move/drive, **E** enter/exit car, **mouse** aim, **click** shoot, **P/Esc** pause.
