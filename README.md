**SOLARA BAY — Streets of the Bay**: an original sun-soaked open-world crime game in a fictional bay city. Steal cars, outrun the SBPD, and work your way up through 7 staged story missions with a 3-person crew (Swap Plates, Quick Fix, Eyes Out), district standing across 7 named districts, street races, taxi fares, 8 hidden Sun Shells, a day/night clock, and a stats screen — all drawn in code, all sound synthesized, zero network requests.

## How to run it
```sh
python3 -m http.server 8080 --directory game
```
Then open http://localhost:8080 in desktop Chrome. Drive with WASD, aim with the mouse, click to shoot, E to enter/exit cars, Q/R for crew abilities, P to pause.
