## SOLARA BAY — Streets of the Bay

A top-down 2D open-world crime game set in a sun-soaked coastal city. You are a
small-time driver working your way up: steal cars, outrun the police, and finish
four story missions — First Wheels, The Pickup, Turfwars, and The Getaway.

The city is a full grid world with traffic, pedestrians, a beach, a downtown, a
garage home base and a safehouse. Drive with drift physics, get in and out of
cars, shoot on foot, raise your wanted level, and escape real police chases.
Everything is drawn in code and all sound is generated with WebAudio — no
network requests, no external assets.

### How to play

- **W A S D / arrows** — walk, or drive when in a car
- **E** — enter / exit a car
- **Mouse + click** — aim and shoot (on foot)
- **P / Esc** — pause (progress saves automatically)
- **M** — mute

### How to run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser.
