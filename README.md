**SOLARA BAY — Streets of the Bay** is a top-down 2D open-world crime game in a
sun-soaked coastal city. Steal cars, outrun the police, and work your way up
through **7 story missions** — from your first stolen wheels to the final casino
job, "The Big One". Between jobs, take repeatable **taxi side jobs** (+$150 a
fare), hunt 3 **hidden stashes**, and cruise the beachfront promenade, the park,
the marina and the neon downtown. A motorbike and a truck join the regular cars
on the road, all stealable and drivable.

## How to run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network
requests: every script, sound and image is drawn or synthesized in code.

## Controls

- **WASD** — drive / walk
- **E** — enter / exit car
- **Mouse** — aim, click — shoot
- **P / Esc** — pause (Resume / Restart mission / Quit to title)
- Progress saves automatically; Continue on the title screen picks up where
  you left off.
