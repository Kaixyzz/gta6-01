**SOLARA BAY — Streets of the Bay**: an original sun-soaked open-world crime game in a fictional bay city that never existed. Steal cars, outrun the SBPD, and work seven staged story missions with a three-person crew — Rosa Vega (driver), Tomas Ibarra (mechanic) and Nia Solano (lookout) — while your standing rises across seven named districts. Between jobs, run repeatable taxi fares, race the Promenade Sprint and Harbor Loop, and hunt 8 hidden Sun Shells. Day/night clock, dense career stats, three save slots, and a wanted system with named SBPD dispatch units and a police helicopter.

## How to run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. Keyboard and mouse: WASD to drive/walk, E to enter/exit cars, mouse to aim, click to shoot, Q for Swap Plates, R for Quick Fix, P/Esc to pause and see stats.
