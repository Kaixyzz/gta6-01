**SOLARA BAY — Streets of the Bay** is a top-down 2D open-world crime game
in a sun-soaked coastal city. Steal cars, outrun the police, and work your
way up through **6 story missions** — from your first stolen wheels to the
boss's own sports car — with a wanted level, real police chases, on-foot
combat, and **3 hidden stashes** to find around the city. Drive a sedan, a
fast **motorbike**, or a heavy **truck**; traffic and pedestrians fill the
streets, and the whole city is drawn with code — no downloaded assets.

## How to run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. No build step, no
network requests — everything the game needs is a file under `game/`.

## Controls

- **WASD** — drive / walk
- **E** — enter & exit a car
- **Mouse** — aim, **click** — shoot
- **P** — pause (menu: resume / restart mission / quit to title)

Progress saves automatically; Continue on the title screen picks up where
you left off, and finishing the story shows the Story Complete card.
